# Evidence Notes

The public repository intentionally excludes raw crash reports, report identifiers, personal email addresses, unredacted invoice files, and other sensitive source material.

The private archive includes 45 production invoices, hiring and screening correspondence, assignment instructions, mapping and technical correspondence, audit results, workflow changes, corporate-transition correspondence, and end-of-project communication.

The total is described as **20,865 documented record actions**, not 20,865 unique crashes, because some records could later receive updates or re-enter parts of the workflow.

Audit language is described as **repeated documented 100% scores**, not a perfect score every week.
